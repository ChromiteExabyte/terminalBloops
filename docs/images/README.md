# Screenshot provenance

These are renders of the actual WPF application, generated by its explicit `--self-test` diagnostic. Every displayed process, launcher and command is a synthetic test fixture. No live user history or recorder diagnostics are included.

| File | Source |
| --- | --- |
| `history-light.png` | `timeline.png` from the UI smoke test |
| `history-dark.png` | `timeline-dark.png` |
| `event-details.png` | `timeline-expanded.png` |
| `high-contrast.png` | `timeline-high-contrast.png` |
| `notification.png` | `notification.png` |
| `icon.png` | 128 px frame from the application's original `.ico` asset |

The renders show the application's client area; Windows draws the native caption separately. Sample timestamps are generated when the test runs. High contrast is rendered using the corresponding Windows system colors.

To regenerate the source renders, publish the app, then run this from an interactive Windows desktop:

```powershell
$preview = Join-Path $PWD 'artifacts\ui-preview'
$process = Start-Process .\artifacts\publish\TerminalBloops.exe -ArgumentList @('--self-test', ('"' + $preview + '"')) -WindowStyle Hidden -PassThru
$process.WaitForExit()
if ($process.ExitCode -ne 0) { throw 'Inspect the UI verification output before updating screenshots.' }
```

Copy the verified renders using the mapping above. The diagnostic does not install the recorder, write demo entries to the real database, or change startup settings. The icon source is [Generate-Icon.ps1](https://github.com/ChromiteExabyte/terminalBloops/blob/main/scripts/Generate-Icon.ps1); it uses native drawing primitives and no external artwork.
